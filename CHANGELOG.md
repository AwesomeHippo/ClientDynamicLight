# Changelog

### Version 1.20.1 - 3.3.0 (Forge) 2026-11-11
- Any block that emits light now lights up when held or dropped wihout the need of a json rule! (you can still override)
- New waterSensitiveItems config in config_items.json to configure if the items should emit or not light underwater
- Finally reworked and cleaned up the lighting code! (also faster with many light sources now)
- Invalid ids in the json configs are now actually skipped
- Default key to open the config is now O instead of L (L is already for advancement, so...)
- Removed the forge update checker....
- Fixes and improvements overall!:)
- Update EN, FR and ZH translations (thanks google translate for updating the existing ZH lang)

### Version 1.20.1 - 3.2.1 (Forge) 2026-08-10
- Lot of performance improvements when moving with light sources
- Only update lighting for sections in view range & in front of the camera
- Small fixes and updates overall.
- Bump forge version to 47.4.10 (previously 47.2.0) and add clientSideOnly in mods.toml

### Version 1.20.1 - 3.2.0 (Forge) 2026-07-29
- Fix a glitch with shadow artifacts around blocks when switching light sources
- Improve performance

### Version 1.20.1 - 3.1.0 (Forge) 2026-06-23
